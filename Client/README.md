# Hope, Inc. ERP Client

The client is a React application built with Vite. It includes a demo landing page, sign-in and registration flows, a role-aware dashboard, and customer management.

## Run locally

```sh
npm install
npm run dev
```

Vite opens `main.html`. To create a production build, run `npm run build`.

The app stores demo users and customers in this browser's local storage. Demo sign-in accepts any password; this is a front-end demonstration, not production authentication.
