Playwright: Automated Testing Guide
What is Playwright?

Playwright is an automated browser testing tool used by developers and QA testers to check whether a website works properly. Instead of manually opening a website and checking everything, Playwright can automatically open the website, check if the page loads, detect JavaScript errors, click buttons, fill out forms, and test different features. In our Hope, Inc. ERP project, we use Playwright to help identify possible problems and make the testing process faster and easier.

How to install Playwright

Open the terminal in your project's Client folder and run the following command to install Playwright:

npm install --save-dev @playwright/test

After installation, download the Chromium browser that Playwright will use for testing:

npx playwright install chromium

How to create the test file

Inside the Client folder, create a folder named tests. Inside that folder, create a JavaScript file named smoke.spec.js. This file will contain the automated test code for our ERP application.

Playwright test code

Copy the following code into tests/smoke.spec.js:

import { test, expect } from '@playwright/test';

test('Hope ERP page loads successfully', async ({ page }) => {
  const errors = [];

  // Detect JavaScript errors
  page.on('pageerror', error => errors.push(error.message));

  // Open the ERP website
  const response = await page.goto(
    'http://127.0.0.1:5174/main.html'
  );

  // Check if the page loaded successfully
  expect(response.status()).toBe(200);

  // Check if the page contains content
  await expect(page.locator('body')).not.toBeEmpty();

  // Check if there are JavaScript errors
  expect(errors).toEqual([]);
});

How to run the Playwright test

First, open a terminal in the Client folder and start the ERP application using this command:

npm run dev -- --host 127.0.0.1 --port 5174 --strictPort

Keep the terminal running. Open another terminal in the same folder and execute the following command:

npx playwright test tests/smoke.spec.js --reporter=list

How to understand the results

If the test is successful, the terminal will display something similar to:

✓ tests/smoke.spec.js
  Hope ERP page loads successfully

1 passed

This means the website responded successfully, the page contained content, and no uncaught JavaScript errors were detected. If the test fails, Playwright will display an error message showing which check did not pass.

Conclusion

Playwright is useful for our Hope, Inc. ERP project because it helps the QA Tester perform automated browser testing. It reduces repetitive manual work and makes it easier to repeat tests whenever the developers update the application. However, this particular test only checks whether the page loads correctly and whether JavaScript errors occur. Other features, such as login, customer management, and user permissions, require separate test cases.
